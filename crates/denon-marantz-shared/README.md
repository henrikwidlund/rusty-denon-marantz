# denon-marantz-shared

Internal helpers of the
[`denon-marantz`](https://crates.io/crates/denon-marantz) and
[`denon-marantz-heos`](https://crates.io/crates/denon-marantz-heos) crates:
TCP connections, host names and request handling of the background tasks.

The API is not stable. Do not use this crate directly.

Minimum supported Rust version: 1.100.
